# Проекты карьеры

Здесь я описал 3 главных этапа карьеры Роналду.

## 1. Manchester United

![Manchester United](images/ronaldo-manutd.jpg){ width="280" }

Роналду пришёл в клуб в 2003 году. Здесь он стал звездой мирового футбола.

**Технологии / навыки того времени:**

- дриблинг
- скорость
- удар

Ссылка: [Manchester United](https://www.manutd.com/)

## 2. Real Madrid

В «Реале» (2009–2018) Роналду забил очень много голов и выиграл Лигу чемпионов несколько раз.

**Что важно:**

- рекорды по голам
- трофеи
- мировой бренд CR7

Ссылка: [Real Madrid](https://www.realmadrid.com/)

## 3. Сборная Португалии

![Сборная Португалии](images/ronaldo-portugal.jpg){ width="280" }

Роналду — капитан сборной. Вместе с командой он выиграл Евро-2016.

Ссылка: [FPF](https://www.fpf.pt/)
